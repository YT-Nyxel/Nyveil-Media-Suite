## 6. GPLv3 source availability / Quellcode

Nyveil Media Suite is distributed as object code (the Windows EXE) and includes GPLv3-licensed components. Under GPLv3, recipients are entitled to the **complete corresponding source code** for the version they received.

**Source availability:** the complete source archive for each release is attached to the **same GitHub release** as the EXE (asset name `Nyveil-Media-Suite-<version>-source.zip`). If the source asset is missing or inaccessible, request it by email at **Nyveil@web.de**. The offer is valid for at least three years from the date you received the binary.

The source archive includes the application source, build configuration, and the information needed to rebuild the distributed version. It does not include your personal data, TURN credentials, or third-party media. See [SOURCE_OFFER.md](SOURCE_OFFER.md) for details, including the exact FFmpeg and PyAV/FFmpeg source information.

**If you do not want to publish the source:** the current build cannot be distributed under GPLv3 without making the corresponding source available. The alternative is to remove or replace the GPL-linked PyAV/FFmpeg libraries (the components loaded inside the application process) with permissively licensed alternatives. The standalone `ffmpeg.exe` is a separate program, but it still requires its own GPLv3 source offer if you keep it. Removing the in-process GPL components is a code and dependency change, not merely a documentation change.
