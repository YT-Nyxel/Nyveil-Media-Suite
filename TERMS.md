## 1. What the app is

Nyveil Media Suite is a free Windows desktop tool that:

- downloads publicly accessible media with `yt-dlp`;
- converts local media with the bundled FFmpeg binary;
- plays public media streams using a locally installed VLC runtime;
- sends a single file directly to another installation using WebRTC data channels.

The app is a tool. It does not provide, host, curate, or endorse media. It has no account system and no Nyveil server.
